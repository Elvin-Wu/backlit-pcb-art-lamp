# Credits

## PCB Artwork Tool

The layered artwork used for the front PCB was generated using a translucent PCB artwork tool shared by the Bilibili creator **不是孙小华呀**.

The tool was used to generate the image layers, which were then imported into the EDA software and adapted for this PCB design.

- Creator: [不是孙小华呀](https://space.bilibili.com/1031031979)
- Platform: Bilibili
- Tutorial: [白嫖pcb透光画（喂到嘴里的教学）](https://www.bilibili.com/video/BV14NR6YPEYC/)

## Artwork

The source image used for the artwork PCB is an AI-generated sample image included with the tool package.

The exact prompt and generation process used for this particular image were not provided by the creator. The tutorial demonstrates the image-generation workflow using a separate example.

I did not create the original AI-generated source image.
